# Verbindliche Projektgrenzen

- Den Nutzer Buddy nennen und technische Dinge einfach erklären.
- Ausschließlich Dateien im JARVIS-Checkout bearbeiten.
- Andere Projektordner, insbesondere HermesAI-ha, CreOS und WHBoard, sind absolut schreibgeschützt. Dort niemals Dateien ändern, erzeugen, löschen oder verschieben, Software installieren, Builds/Formatierungen ausführen oder committen/pushen. Auch keine schreibenden APIs dieser Projekte aufrufen.
- Referenzdateien dürfen gelesen werden. Ein erkannter Fehler in einem Referenzprojekt ist keine Erlaubnis, ihn dort zu beheben.
- Commit und Push übernimmt der Nutzer mit GitHub Desktop.
